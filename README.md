# Nicholas Fernandez — Portfolio

Static site (HTML + CSS), ready for Vercel with no build step.

## Add project images
Drop these files into `images/`:
- `images/morphix.jpg`
- `images/clawd-buddy.png`

Until they exist, a striped placeholder shows the expected filename.

## Deploy
Import this GitHub repo at vercel.com/new. Framework preset: **Other**. No build command needed.
